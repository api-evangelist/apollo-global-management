# Apollo Global Management

> Apollo Global Management (NYSE: APO) is a global alternative asset manager and
> retirement services provider, running private equity, credit and real assets
> strategies for institutional investors, family offices and global wealth channels.
> Apollo runs no public developer program: it publishes no OpenAPI, no GraphQL schema,
> no AsyncAPI, no SDKs and no developer portal. It does operate one machine-readable
> surface — an OAuth 2.0 authorization server on api.apollo.com fronting a Model Context
> Protocol endpoint — which is undocumented and reachable only with an authenticated
> Apollo client identity.

Generated by the API Evangelist enrichment pipeline on 2026-09-04 from apis.yml and the
artifacts in this repository. Every statement below is backed by a probe recorded in
well-known/apollo-global-management-well-known.yml. Not published by Apollo.

## Disambiguation

- This is Apollo Global Management, apollo.com. It is NOT Apollo.io (apollo.io, sales
  intelligence) and NOT Apollo GraphQL (apollographql.com, the GraphQL platform). Both of
  those publish MCP products; neither is this company.
- client.apollo.com and investor.apollo.com run Vega AltOS, a third-party private-markets
  client-service platform in which Apollo is an investor and anchor client. The
  `api://vega-mcp` resource those hosts advertise belongs to Vega, not to Apollo.

## Machine-readable surface

- [OAuth authorization server metadata](https://api.apollo.com/.well-known/oauth-authorization-server): RFC 8414. Issuer https://api.apollo.com. Authorization, token and dynamic client registration endpoints under /mcp/. PKCE S256 required, public client, refresh tokens supported.
- [OpenID Connect discovery](https://api.apollo.com/.well-known/openid-configuration): byte-identical to the RFC 8414 document; missing jwks_uri and the other OIDC-required fields.
- [MCP protected resource metadata](https://api.apollo.com/.well-known/oauth-protected-resource/mcp): RFC 9728. Declares https://api.apollo.com/mcp as the protected resource, scopes openid, profile, email.

## What an agent can and cannot do

- An MCP client can complete dynamic client registration and an authorization-code + PKCE
  flow against api.apollo.com, but the resulting session requires an Apollo user account.
- Anonymous requests to https://api.apollo.com/mcp return HTTP 404 at the edge — not a 401
  challenge — so the tool list, tool descriptions and input schemas are unknown. They are
  not recorded in this repository because they were never observed.
- There is no REST, GraphQL, SOAP or gRPC contract to fall back on. Probes of
  /openapi.json, /openapi.yaml, /swagger.json, /v1/openapi.json, /api-docs, /docs, /redoc,
  /graphql and ?wsdl on www.apollo.com and api.apollo.com all missed.
